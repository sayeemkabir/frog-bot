## Intro

Welcome to Frog Bot. It is a desktop app where AI agents work like teammates on your computer.

## 01-onboarding.png

The first time you open Frog Bot, it asks for an API key from Claude or OpenAI. Then you can start chatting with Frog right away.

## 02-home.png

This is the main home screen. Your agents and groups are on the left, the chat is in the middle, and quick suggestions help you begin.

## 03-new-agent.png

Use the plus button to add a new agent. Give the agent a name, an emoji, a color, a simple role, and plain instructions for how it should help.

## 04-group.png

You can also create group chats with more than one agent. In a group, type @Name when you want to speak to one specific teammate.

## 05-chat.png

Chat with Frog the same way you would chat with a coworker. Agents can read and write files, research the web, use a browser, run commands, and ask other agents for help.

## 05b-approval.png

When an agent wants to do something important, Frog Bot asks first. You can allow it, say no, open details, or stop the work at the top of the chat.

## 05c-approved.png

After you approve an action, the agent continues and reports what happened. This keeps you in control while still letting the team do real work.

## 06-panel-details.png

The About panel shows how an agent is set up. You can edit its name and instructions, choose its brain, pick which apps it can use, and decide whether it can work on its own.

## 06-panel-computer.png

The Screen tab lets you monitor the agent's computer. You can see its live steps, so you always know what it is doing.

## 07-integrations.png

Integrations connect Frog Bot to the tools you already use. The browser is built in, and you can add apps like Slack, Notion, GitHub, Linear, or custom apps.

## 08-integration-form.png

To add another app, fill in the server address and a token if one is needed. Then click Add, and the app becomes available to your agents.

## 09-logs.png

The Logs tab shows a live record of everything that happens. You can filter it, copy it, or save it when you need to review the work.

## 10-settings.png

Settings are where you manage the basics. You can update your API key, team name, default brain, startup options, screen learning, and where files are stored.

## Outro

That is the flow of Frog Bot. Create agents, give them work, watch their progress, connect your apps, and find shared files whenever you need them.
